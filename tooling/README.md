# Source-built fabrication fixes

These three packages are local forks, **not official upstream releases**. They
are installed by the board's locked Bun overrides. The ordinary `tsci` commands
load the board's core package; there is no runtime monkey patch and no Gerber or
Circuit JSON rewriting. Every published package archive is hashed in
`manifest.json`, alongside its official upstream Git commit and source patch.
Upstream licenses are preserved in `licenses/`.

- **props/core:** explicit `solderPasteDisabled` on plated holes. The optional
  boolean leaves existing shape-specific behavior unchanged when omitted or
  false. True omits paste on both sides, while retaining the original copper,
  drill, mask, and connectivity. It does not conflict with mask properties.
  The board sets it only on J2–J6. The core version reporter also returns the
  actual package version, including its local prerelease suffix.
- **alphabet:** adds U+2022 BULLET to the stroke alphabet and advance metrics.
  Outlines and the TTF/base64 font are regenerated by the upstream scripts.

Validation: props parsing/default/rejection tests and typecheck pass; core
typecheck, canonical build, version test, and 17 relevant plated-hole/paste
regressions pass; all 10 alphabet tests pass. New visual snapshots were rendered
and inspected. Upstream font generation emits one Boolean-union warning on both
the unchanged baseline and this fork; the added bullet's stroke, polygon, and
TTF exports pass explicit regression checks. DejaVu comparison tests report that
the optional reference font is absent; they are not counted as comparisons.

`python3 scripts/rebuild-tooling.py` reconstructs the source checkouts under
`.tscircuit/rebuild-toolchain/`, applies the source patches, copies the regression
tests, regenerates props docs/font outputs, checks and builds the packages, and
packs them into that folder's `packages/`. It requires network access, Bun 1.3.9,
Python 3.14, the standard `patch` command, and yalc 1.0.0-pre.53. It uses the
handbook's yalc workflow only between source packages. It does not replace the
board's reviewed package archives or publish anything. Inspect any rebuilt
package before updating the manifest and lockfile.

The source fixtures in `regression-tests/` compile and run in their respective
upstream repositories, not as board circuit sources.

tested props and alphabet. Core's fresh dependency installation stalled without
